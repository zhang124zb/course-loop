# CourseLoop · 本机教学演示与课赛融合原型

本项目包含两个运行入口：**本机教学版**具有真实登录、数据库、资源与任务管理、固定示例运行及 Ollama 教师诊断；**GitHub Pages 线上版**继续用于四域交互原型展示。

## 本机教学版

面向大学 Python 程序设计课程，使用明确标注的模拟班级与学生。默认只绑定 `127.0.0.1:8080`，适用于一个人使用不同账号演示，不开放局域网和公网。

1. 在 Windows 上安装 Python（本次验证版本 3.14.6）。
2. 双击 `启动本机教学.cmd`。首次启动需联网安装锁定依赖，之后正常运行无需重复安装。
3. 查看本机 `.runtime/demo-accounts.txt` 中独立生成的管理员、教师和学生账号；切换角色前先退出。
4. 打开 `http://127.0.0.1:8080/`。

本机 Ollama 使用已安装的模型，不会自动下载模型。启动脚本会在服务未运行时尝试后台启动；当前默认模型为 `qwen3.5:4b`，管理员可配置 OpenAI 兼容服务地址、模型与密钥。

- 学生：访问已发布课程资源，记录学习完成，提交代码并查看自己的反馈。
- 教师：维护分层资源与不可变题目版本，安排课前、课中、课后任务，查看班级提交与学习记录，生成并确认 AI 教学建议。
- 管理员：创建与停用账号、重置密码，维护课程与班级名单，配置和测试模型，查看操作日志。
- 代码评测：只真实运行服务器固定、哈希校验通过的六份已审核示例；学生编辑代码只保存为待评测，不作为错误或零分。教师新增题目不自动获得执行权限。
- AI：按当前班级名单及每名学生最新提交生成报告，保留证据快照；不自动发布任务、执行代码或改分。学生聊天答疑留待后续扩展。

技术栈：Django 5.2.18 LTS、SQLite、Waitress、服务器端模板；密钥使用 Fernet 加密保存。依赖版本见 `requirements.lock`。学校多人部署前需迁移与验收，不能直接把本机演示版开放出去。

运行数据、账号文件、上传附件和本机密钥均位于 `.runtime/`，已排除出 Git。**该工作目录位于 OneDrive；请核对自己的同步设置。真实学校数据或真实服务密钥启用前，应把运行数据迁移到学校认可且不自动同步的位置。**

## GitHub Pages 线上交互原型

> **这是交互原型，不是正式教学系统。** 所有班级、学生、成绩、赛程和反馈均为示例数据。AI 建议与代码评测为预设流程演示，没有接入真实模型或代码执行沙箱。

CourseLoop 探索“教学 → 自主实训 → 三级竞赛 → 过程评价 → 教学改进”的完整链路，支持学生、教师、管理员三个演示视角。

- [在线原型](https://zhang124zb.github.io/course-loop/)
- [博客首页](https://zhang124zb.github.io/)
- [原型介绍文章](https://zhang124zb.github.io/posts/course-loop-prototype.html)

## 可以体验什么

- **教**：课前预习、课中实操、课后训练，以及教师审核教学诊断建议。
- **学**：三层资源、基础/进阶/项目任务、预设代码纠错与新题复测。
- **赛**：单元闯关、月度挑战、校级选拔与等价考核，组赛草案和教师发布。
- **评**：四维权重、过程试算、证据说明、项目量规、报告导出和评价异议。
- **闭环**：发现问题 → 教师确认 → 针对补练 → 新题复测 → 教师验证。

## 推荐体验顺序

1. 学生视角进入“分层实训 → 列表平均值与空输入”，运行边界遗漏示例。
2. 查看递进提示，切换到订正示例并提交，再查看过程评价的变化。
3. 切换教师视角，查看诊断报告并确认安排训练与复测。
4. 学生完成 T101 和 T203；教师核对证据后确认改善，关闭干预。
5. 教师调整四维权重、创建赛事草案，或按量规评价项目。
6. 管理员可以新增资源、导出体验数据或恢复初始样例。

## 本地运行

需要 Node.js。应用没有第三方运行依赖：

```sh
npm start
```

打开 `http://127.0.0.1:4173`。也可以直接打开 `dist/index.html`。

```sh
npm run check
```

## GitHub Pages

仓库使用 `.github/workflows/pages.yml` 将 `dist/` 发布到 GitHub Pages。推送 `main` 后自动检查脚本语法并部署。

GitHub Pages 的发布来源设置为 **GitHub Actions**。项目站点使用 `/course-loop/` 子路径，静态文件采用相对引用，页面采用哈希路由。

## 线上静态原型的数据与实现边界

- 数据仅保存在当前浏览器，不会跨设备同步。
- 角色切换是演示功能，不是真实登录或服务端权限。
- 代码评测只匹配预设示例，不执行任意代码。
- AI 助教、诊断与组赛建议是演示模板，不调用真实模型。
- 项目文件只记录文件名，不读取或上传文件内容。
- 四维分数为过程试算，不形成正式教务成绩。

请勿输入真实学生个人信息或把本原型用于正式考试。后续建设需补齐身份、服务端数据、隔离判题、模型验证和正式评价制度。

## 文件结构

```text
dist/                      静态网页、样式、交互与示例数据
.github/workflows/pages.yml GitHub Pages 自动部署
serve.mjs                  本机预览服务
package.json               运行与语法检查命令
验证记录.md                 原型浏览器检查记录
```

本项目曾完成 18 项浏览器交互检查；详见[验证记录](验证记录.md)。这些检查不等同于生产安全审计、性能压测或教学效果验证。
