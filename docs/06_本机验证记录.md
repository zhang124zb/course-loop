# 本机教学版验证记录

日期：2026-10-22。范围：一个人在 Windows 本机使用模拟班级，教学域真实业务，Ollama 教师诊断；不代表学校生产验收或正式教学效果验证。

## 环境

- Python 3.14.6、Django 5.2.18、Waitress 3.0.2、SQLite。
- 密钥加密依赖最终为 cryptography 50.0.2。初选47.0.0在依赖审计中发现已知安全公告，已按[官方修复记录](https://cryptography.io/en/latest/changelog/)升级并重新验证。
- Ollama 0.40.7，实际使用已安装的 `qwen3.5:4b`；模型目录为本机既有 `D:/Ollama/models`，未下载新模型。
- 教学服务仅绑定 `127.0.0.1:8080`，Ollama 仅绑定 `127.0.0.1:11434`。
- Chrome 无界面独立配置；桌面宽1440、手机宽390。未使用用户日常浏览器配置。

## 已通过的验证

35 项自动化测试全部通过，覆盖：角色与对象权限、未发布任务隐藏、跨班与同班他人提交隔离、CSRF、仅POST写入、固定示例真实运行、编辑代码不执行、幂等提交、关闭任务拒绝提交、文本输出转义、附件类型与私有下载、旧题目版本不可修改、模型密钥加密及不回显、切换服务不能沿用旧密钥、自定义地址限制及私网解析拒绝、异常模型响应、慢滴响应总时限、AI失败保留证据、当前名单和最新提交统计、教师确认、备份必要文件及可解密性。

12 项真实浏览器流程通过：

1. 学生使用本机生成的独立账号真实登录。
2. 学习完成记录写入数据库。
3. 边界遗漏示例真实运行，2/3用例通过。
4. 订正示例真实运行，3/3用例通过。
5. 学生编辑代码保存待评测，后台返回空分数，未执行代码。
6. 学生四类手机页面无横向溢出。
7. 教师使用独立账号真实登录。
8. 从真实保存的提交证据调用本地 Ollama，生成教师建议报告。
9. 教师通过POST确认采纳。
10. 管理员独立登录并查看实际模型配置，密钥输入不回显。
11. 管理员四类手机管理页面无横向溢出。
12. 上述流程没有未处理的前端脚本异常。

真实报告快照使用4名模拟学生的最新提交：3人已评测、1人待评测，已评测示例均分77.8。后台证据与模型文字分别展示；模型文字仍可能遗漏或判断错误，需教师复核。模型没有发布任务、执行代码或修改分数的工具权限。

另已通过 Django 系统检查、迁移漂移检查、依赖一致性检查及两份 JavaScript 语法检查。Windows PowerShell 5.1 启动脚本实际完成迁移检查、幂等初始化和服务启动。

pip-audit 2.10.1 对最终锁定清单的8项依赖返回“No known vulnerabilities found”。这是查阅当时漏洞数据库的结果，不等于不存在未知漏洞，也不覆盖操作系统或整机软件。GitHub 自动检查配置同时包含业务边界测试和依赖审计。

## 备份与恢复实测

停止教学服务后执行 SQLite 在线备份接口生成快照，并检查必要文件、哈希、数据库完整性、附件引用和密钥条件。

随后把该快照复制到独立的本地恢复目录，以 `COURSELOOP_RUNTIME_DIR` 指向恢复目录加载系统：管理员、教师、学生三种账号均能通过真实密码认证；6个附件均可找到；27条提交、4份报告和其中1份已完成AI报告可读取。

恢复验证未覆盖正式学校数据库迁移、跨机器灾备或大文件上传时的一致性；本机备份前仍要求停止服务和上传操作。

## 评审发现与修复

- 修正种子题面与固定测试用例不一致的问题，保持固定执行源码和哈希不变。
- 修正本机HTTP登录的请求来源策略，保留CSRF校验。
- 修正异常模型响应可能触发服务器错误，以及慢速响应可能突破总等待时限的问题。
- 修正更换模型服务域名时旧密钥可能被转发的问题。
- 修正诊断混入已移出学生的历史提交问题。
- 修正密码重置表单失败后丢失目标账号的问题。
- 加强备份检查，并修正Windows下SQLite连接未关闭导致文件被占用的问题。

## 已知范围与未验收部分

- 当前不是任意Python代码隔离沙箱，只有固定仓库示例可以执行。
- 种子资源中的微课内容包含讲解脚本，不冒充已录制视频。
- 赛、评、学生聊天答疑、校级多人使用、正式成绩、跨设备同步尚未完成本期真实验收。
- SQLite、进程内节流与单模型并发限制按本机单人范围设计；学校上线前需要独立部署和负载、安全、恢复验收。
- 模型输出质量只做本次示例核对，不证明对所有程序的诊断准确率，不证明教学效果提升。
- `.runtime` 当前位于OneDrive工作目录，应在使用真实学校数据或真实服务密钥前确认同步策略或迁移运行目录。

本记录不把代码中声明的功能、静态原型或通过少量测试视为生产安全保证。
