# 本机教学版验证记录

日期：2026-10-22。范围：一个人在 Windows 本机使用模拟班级，教学域真实业务，Ollama 与 DeepSeek 教师诊断；不代表学校生产验收或正式教学效果验证。

## 环境

- Python 3.14.6、Django 5.2.18、Waitress 3.0.2、SQLite。
- 密钥加密依赖最终为 cryptography 50.0.2。初选47.0.0在依赖审计中发现已知安全公告，已按[官方修复记录](https://cryptography.io/en/latest/changelog/)升级并重新验证。
- Ollama 0.40.7，实际使用已安装的 `qwen3.5:4b`；模型目录为本机既有 `D:/Ollama/models`，未下载新模型。
- 教学服务仅绑定 `127.0.0.1:8080`，Ollama 仅绑定 `127.0.0.1:11434`。
- Chrome 无界面独立配置；桌面宽1440、手机宽390。未使用用户日常浏览器配置。

模型曾把代码格式推断写为已证实；收紧提示后重新生成，要求代码推断列为待核查。报告仍可能误判，例如格式与“运行错误”概念需要教师核对；确定性提交统计另列为证据，不以模型文字替代。没有证明模型诊断准确率或教学效果。

运行目录已从 OneDrive 工程目录复制校验至本机非同步目录，旧数据保留；新目录权限限制为当前用户与系统。启动、管理命令及备份读取同一份私有操作人配置。真实密钥只加密保存在新目录，页面未回显。包含加密 DeepSeek 配置、6个账号与27条提交的备份已通过完整性、附件与可解密性检查。

## 备份与恢复实测

停止教学服务后执行 SQLite 在线备份接口生成快照，并检查必要文件、哈希、数据库完整性、附件引用和密钥条件。

随后把该快照复制到独立的本地恢复目录，以 `COURSELOOP_RUNTIME_DIR` 指向恢复目录加载系统：管理员、教师、学生三种账号均能通过真实密码认证；6个附件均可找到；27条提交、4份报告和其中1份已完成AI报告可读取。

恢复验证未覆盖正式学校数据库迁移、跨机器灾备或大文件上传时的一致性；本机备份前仍要求停止服务和上传操作。

## 评审发现与修复

- 修正种子题面与固定测试用例不一致的问题，保持固定执行源码和哈希不变。
- 修正本机HTTP登录的请求来源策略，保留CSRF校验。
- 修正异常模型响应可能触发服务器错误，以及慢速响应可能突破总等待时限的问题。
- 修正更换模型服务域名时旧密钥可能被转发的问题。
- 修正诊断混入已移出学生的历史提交问题。
- 修正密码重置表单失败后丢失目标账号的问题。
- 加强备份检查，并修正Windows下SQLite连接未关闭导致文件被占用的问题。

## 已知范围与未验收部分

- 当前不是任意Python代码隔离沙箱，只有固定仓库示例可以执行。
- 种子资源中的微课内容包含讲解脚本，不冒充已录制视频。

- SQLite、进程内节流与单模型并发限制按本机单人范围设计；学校上线前需要独立部署和负载、安全、恢复验收。
- 模型输出质量只做本次示例核对，不证明对所有程序的诊断准确率，不证明教学效果提升。
- 默认运行目录仍可位于工程内；本次真实服务配置已迁至私有非同步目录，使用者需按指南完成各自的迁移与权限设置。
