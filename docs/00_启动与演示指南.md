# CourseLoop 本机教学演示指南

适用范围：Windows 本机、模拟学生数据、一个人按独立账号依次演示。博客公开页面仍为原型与本机入口说明。当前不是已验收的学校生产系统。

## 启动

在工程目录双击 `启动本机教学.cmd`，或在 PowerShell 执行 `./start-local.ps1`。首次需要联网建立 Python 环境并安装锁定依赖；本次验证使用 Python 3.14.6。

启动时执行数据库迁移与幂等样例初始化，不重置已有密码、不重复插入提交。随后启动仅绑定 `127.0.0.1:8080` 的服务并打开浏览器。关闭服务窗口或按 Ctrl+C 可停止教学服务。

若本机 Ollama 未运行，脚本会尝试后台启动已安装的 Ollama，不下载模型，不修改系统级环境配置；本脚本新启动的服务关闭云模型与自动清理，仅访问本机。若模型安装在 Ollama 程序同目录的 `models` 下，会优先识别该位置；其他自定义目录可在启动前设置当前进程的 `OLLAMA_MODELS`。

## 获取账号

账号文件位于工程内 `.runtime/demo-accounts.txt`。使用 `admin`、`teacher`、`student1` 至 `student4` 对应的各自随机密码。文件只保存在本机，不会上传 GitHub。

没有公开注册，也没有浏览器角色切换器。请先点“退出”，再使用另一账号登录。忘记密码可由管理员重置；首次管理员账号恢复需由本机操作人处理，不提供公开重置入口。

## 演示前准备

1. 打开 `http://127.0.0.1:8080/`，确认登录页可访问。
2. 使用管理员进入“模型服务”，确认地址为 `http://127.0.0.1:11434/v1`，模型为本机已安装模型。本机 Ollama 不需要填写服务密钥。
3. 点击“测试连接”，或在工程目录运行 `.\.venv\Scripts\python.exe server/manage.py warm_ai` 预热。首次加载可能需要1—2分钟。
4. 检查任务题面、三层样例资源和班级名单。微课层级的部分种子内容为讲解脚本，明确标注尚未配置真实视频；不要将其介绍为已拍摄微课。

## 建议的演示顺序

1. 学生登录：打开基础资源并记录完成，进入“列表平均值与空输入”任务。
2. 填入“边界遗漏示例”提交，查看实际用例运行及空输入失败；再提交“订正示例”查看通过结果。
3. 修改任意代码再提交，展示它被真实保存为“待评测”，不会在本机执行，也不会得到假分数。
4. 教师登录：查看当前班级的任务、提交和资源完成记录；根据实际记录生成 AI 教学建议，核对班级人数、待评测人数及失败用例。
5. 教师确认采纳：记录审阅时间，展示 AI 不能自动发布任务或改变成绩。
6. 管理员登录：展示账号、课程班级、模型配置、连接测试与操作日志。新增课程后可建立自己的班级、资源和任务。

赛、评在本期保留原型及明确返回未实现状态的扩展接口。学生聊天答疑在后续阶段建设，本期 AI 优先服务教师诊断。

## 模型与故障处理

教学记录不依赖模型服务才能保存。模型未运行、模型不存在、超时或返回异常格式时，报告显示失败并保留证据；不会替换成预设成功报告。启动 Ollama、检查模型名称后可以重试。

管理员修改 OpenAI 兼容地址前，外部 HTTPS 域名须由本机操作人通过 `COURSELOOP_AI_ALLOWED_HOSTS` 显式允许，之后重启服务。默认不允许外部域名，仅允许固定本机 Ollama 地址。切换不同服务域名时，必须填写新密钥或明确清除旧密钥，避免将旧密钥转发给其他服务。

服务密钥不回显、不进入页面与审计日志。`.runtime/ai-master.key` 与数据库需要一并备份；仅备份数据库不能保证恢复密钥。

## 备份与恢复

停止教学服务，确认没有上传或更新记录，再执行：

```powershell
.\.venv\Scripts\python.exe tools/backup_local.py
```

备份位于 `.runtime/backups/时间戳/`。验证程序会检查数据库完整性、所有登记文件的哈希、必要密钥、数据库引用的附件，以及已配置密钥能否解密。可用 `--verify 备份目录` 再次验证，不覆盖运行数据。

需要恢复时，先停止服务并另行保存当前 `.runtime`。把同一份已验证备份的数据库、Django 密钥、模型主密钥（如有）、账号文件和 `uploads` 恢复到 `.runtime`，不要将不同备份的数据库与主密钥混用。恢复后重新启动并验证登录、附件和模型连接。

本地同盘备份不能代替异地灾备；本工程位于 OneDrive，正式数据或真实 API 密钥启用前需确认同步策略和独立运行目录。可以在启动前设置当前进程的 `COURSELOOP_RUNTIME_DIR` 为本机操作人选择的非同步目录，并把同一份备份恢复到该目录；教学服务、初始化命令与备份命令均读取这个配置。不要只设置新目录后就假定旧数据已迁移。学校部署的安全与恢复要求见迁移文档。
